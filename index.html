System parameters

The model uses the exact coupled equations from the stated kinetic and potential energies. Masses are treated as point-mass equivalents at the specified center-of-mass distances; link rotational inertias are not included separately.

Mathematical model

Generalized coordinatesq = (θ₁, θ₂),   q̇ = (ω₁, ω₂)
Kinetic energyT = ½ Aω₁² + Bω₁ω₂ + ½ Dω₂²
A = m₁b₁² + m₂(a₁² + b₂² + 2a₁b₂ cos θ₂)
B = m₂(b₂² + a₁b₂ cos θ₂),   D = m₂b₂²
Potential energyV = −m₁gb₁ cos θ₁ − m₂ga₁ cos θ₁ − m₂gb₂ cos(θ₁+θ₂) + ½K₁θ₁² + ½K₂θ₂²
LagrangianL = T − V
Equations of motionM(q)q̈ + h(q,q̇) + ∇V(q) = τ
M = [[A, B], [B, D]],   τ = [C₁, C₂]ᵀ
h₁ = A₂ω₁ω₂ + B₂ω₂²
h₂ = −½A₂ω₁²
A₂ = ∂A/∂θ₂ = −2m₂a₁b₂ sin θ₂,   B₂ = ∂B/∂θ₂ = −m₂a₁b₂ sin θ₂
Potential derivativesV₁ = (m₁b₁+m₂a₁)g sin θ₁ + m₂gb₂ sin(θ₁+θ₂) + K₁θ₁
V₂ = m₂gb₂ sin(θ₁+θ₂) + K₂θ₂

At each integration step, the simulator solves the 2×2 mass-matrix system for the angular accelerations, then advances the state using fourth-order Runge–Kutta (RK4).
